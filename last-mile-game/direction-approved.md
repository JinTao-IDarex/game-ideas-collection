# direction-approved.md · 最后一公里游戏原型

## 状态：⏳ 已展示三方向，等待用户选择

## 需求来源
用户在做一款「最后一公里」共享单车通勤游戏（5 分钟内找车→开锁→骑行→到公司打卡），
要求 HTML 可玩原型：地图选车 + 随机车况 + 骑行决策单关版本。未指定风格/品牌 → 走三方向硬门。
（弱 runtime 降级：无 subagent，三版由主 agent 串行产出、互不参考）

## 三版统一内容（design-spec.md）
同一批 6 辆车数据（A 隐伤刹车失灵 / B 无坐垫 / C 隐伤链条断 / D 坐垫湿 / E 无把手 / F 完好但最远）、
同一 HUD（倒计时 04:32 真实走秒 / 体力 / 心情）、同一交互（点击车辆切换详情卡）。

## 用户选择原话
2026-10-19：「想做一个手机版页面样式的，地图页面参考哈罗单车的找车页面」→ 产出方向四，待用户确认是否以此方向做完整版
2026-10-19：「点击页面中的一个车辆的时候，跳出来3-5辆车供选择，其中只有一辆可以使用的」→ 方向四 v2：地图标记改为停车点集群（3 个点，3/4/5 辆），每点随机 1 辆好车 + 明伤直接画在车上 + 隐伤只留线索，选明伤 -5s 且标 ✕，隐伤留悬念；每次加载随机洗牌
2026-10-19：「我要睡觉了，你继续完成剩余的任务」→ 用户授权自主执行，**方向四确认落地为完整版**
产出 `game.html`（完整可玩单关）：找车验车 → 步行过场 → 开锁（扫码成功/网络超时/二维码烧毁→输编号+刮花位博弈）

→ 打卡结算（多维结局：完美通勤/有惊无险/人到了魂没了/迟到 + 六项战绩统计 + 再来一局）

- 找车阶段：验车卡与验车详情由 SVG 手绘图替换为实拍风图片（`bikeImg()` 按车况映射，好车用基准图）。
- 骑行阶段：侧视骑手改为第一视角 POV —— 街景背景随里程横向滚动（`povBg`），底部叠透明底车把前景并带颠簸动画，速度联动颠簸频率；摔倒时整个视角侧倾；刹车隐伤爆发时车把图换成刹车断线版（`evBrake` 内切换）。
- 事件逻辑（红灯/QTE/四种隐伤/弃车换车）与 3 倍速计时全部保留未动。

## v7 步行 POV + 平衡性调优（2026-10-20）
- 新增 `assets/pov-walk.png`：步行过场全屏背景（第一视角走向停车点的一排蓝色单车），叠暗色渐变保证文字可读。
- 平衡性：基准车速 6.4→7.5 m/s（`SPD` 常量，HUD/结算同步引用），骑行全程 125→107 游戏秒；链条事件惩罚由 -50%/-65% 放宽为 -45%/-55%（原数值下断链≈必败，现在极限局剩 0-12 秒或压哨迟到，弃车换车成为有意义的策略）。
- 修复浮点显示 bug：结算页打卡时间秒数小数（`clockStr` 未取整）与「还剩 N 秒」浮点。
- 新增回归工具 `autoplay.js`（playwright 自动跑局：good/bad/chain 三模式，自动选车、输编号、事件决策、输出结算 JSON）。跑局结论：完美局剩 107-155s ✅；刹车隐伤+P3+闯红灯+摔跤剩 99s ✅；湿坐垫+P3+两次闯红灯剩 67s ✅。
- 验证截图：`screenshots/v7-walk.png`、`v7-autoplay-good.png`、`v7-autoplay-bad.png`、`v7-autoplay-chain.png`。

## v8 三大新互动玩法（2026-10-20）
- 验车检查 mini-game：验车面板新增「捏刹车/晃链条/按轮胎/摸坐垫」四项检查，每项 -2s；查到隐患直接排除该车（卡片置灰、禁止选定），四项全检通过给出「放心骑」结论。盲选省时间 vs 检查买确定性的核心博弈成型。
- 猛蹬冲刺：骑行阶段右下角圆形按钮，速度 +35% 持续 2.6s、冷却 6s、每次 -3 体力（体力<8 不可用），POV 画面随冲刺轻微推镜 + 颠簸加快。
- 积水+井盖限时抉择：骑行 560m 处固定触发，2.5 秒内三选一（冲水坑不耗时但心情-8 / 贴右绕井盖 -3s / 急刹推车 -5s），超时摔倒 -6s、体力-10、心情-8。
- autoplay.js 同步更新（obs 事件两种模式 + 猛蹬压测），good/bad 双局回归通过、无 PAGE_ERROR；good 局剩 124s（猛蹬收益可见），bad 局剩 90s（两次摔倒）。
- 验证截图：`screenshots/v8-check.png`、`v8-dash.png`、`v8-obs.png`。

## v9 每日路况随机事件池（2026-10-20）
- 骑行段新增随机事件池：每局从 6 个事件中随机抽 2 个，注入不与固定事件撞车的随机里程位（候选 210/290/400/460/520/620m，间距 ≥40m）。
- 事件池：🌧️ 突然下雨（穿雨衣 -8s / 冒雨硬骑 心情-8）、🏃 同事蹭车（带他 速度-15% 换心情+10 / 拒绝 心情-5）、🛤️ 近路小巷（60% 白赚 120m / 40% 死胡同 -15s）、📱 手机颠掉（-6s 捡 / 心情-12 不管）、🚿 洒水车（-4s 绕行 / 心情-6 硬闯）、🛝 下坡（纯奖励：回血回心情 或 3 秒免费冲刺）。
- 组合方式：固定事件（红灯×2、外卖 QTE、积水井盖）+ 隐伤事件（按车况 1 个）+ 随机池 2 个，每局骑行段事件组合不重复。
- autoplay.js 六种事件全部接入自动决策；四局回归：good×2 完美通勤（117-156s），bad flat+P3 首次迟到（难度成立），bad chain+P3 剩 35s 压哨。无 PAGE_ERROR。
- 验证截图：`screenshots/v9-rain.png`、`v9-alley.png`。

## v10 开场标题页 + 每日挑战（2026-10-20）
- 开场标题页：街景背景 + 玩法三行说明 +「开始冲刺」按钮 + 今日挑战信息（#日期 + 今日最佳）。计时器在标题页不走，点击开始才进入地图。
- 每日挑战：RNG 改为按日期播种的 LCG（`rnd()` 全局可重赋值），同一天车辆布局、好车位、随机事件池抽签完全固定，重开即同图刷成绩；中途概率分支（闯红灯、小巷）仍随决策路径变化。
- 本地最佳成绩：成功打卡按「剩余秒数」存 localStorage（`lastmile-best-<日期>`），结算页展示「🏆 今日新纪录」与「今日最佳 · 布局 #日期」，标题页同步显示；「再来一局」改为「再战今日 · 同一布局」。
- autoplay.js 适配（先 startGame）；两局 good 回归布局一致（PICKED 相同、剩 150/151s 仅 tick 抖动）、无 PAGE_ERROR。
- 验证截图：`screenshots/v10-title.png`、结算纪录见 `v7-autoplay-good.png`（最新覆盖）。

## v11 可重玩性三件套：难度 / 评级 / 成就（2026-10-20）
- 三档难度：摸鱼（6 分钟·检查 -1s）/ 标准（5 分钟·检查 -2s）/ 夺命（4 分钟·检查 -3s·随机事件 3 个）；标题页 chips 切换，计时器实时联动，最佳纪录按 日期+难度 分开存储。
- 评级系统：按剩余时间占比评 S(≥40%)/A(≥25%)/B(≥10%)/C，结算页大号渐变字展示，随纪录保存。
- 成就系统（10 个，localStorage 持久）：首战告捷 / 完美通勤 / 盲选之神 / 摔出来的全勤 / 法外狂徒 / 质检员 / 湿身达人 / 冲刺狂魔 / 压哨传奇 / 地狱归来；结算页展示当局新解锁，标题页显示进度 x/10。
- 生涯战绩：总场次 / 胜场 / 累计摔跤，标题页常驻。
- 回归：标准完美局剩 150s（评级 S）；夺命灾难局剩 9s 压哨，一局解锁 5 成就，无 PAGE_ERROR。
- 验证截图：`screenshots/v11-title.png`、结算见 `v7-autoplay-bad.png`（最新覆盖）。
